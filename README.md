# 프랑스로 들여다본 유럽사회

2026년 가을 프랑스 시위를 통해 유럽의 사회문제를 들여다보는 반응형 인포그래픽 웹페이지.
모바일 중심으로 설계해, 하나의 소스(HTML/CSS/JS)로 데스크탑과 모바일 환경에 모두 대응합니다.
데스크탑에서는 1920 시안의 그리드(가운데 1420px 프레임) 안에 모든 정보가 들어가며, 화면이 작아지면 프레임이 비율 그대로 줄어듭니다.

## 폴더 구조

```
index.html          페이지 본문
css/style.css       모바일·태블릿 스타일 (1023px 이하)
css/desktop.css     데스크탑 스타일 (1024px 이상, 1920 시안 그리드 그대로)
js/main.js          스크롤 효과, 타임라인 강조, 지도 클릭
images/             이미지
fonts/              감탄로드 감탄체(제목용, woff2)
```

## 인터랙션

| 섹션 | 동작 |
|---|---|
| 01 TIMELINE | 스크롤하면 빨간 카드가 하나씩 등장, 지나가는 날짜와 점만 빨간색으로 표시 |
| 04 TRIGGER | 스크롤할 때마다 찢긴 종이 띠가 하나씩 펼쳐지고 내용이 나타남 |
| 06 TWO VIEWS | 인물이 먼저 나오고 말풍선이 이어서 나타남 |
| 07 ACROSS EUROPE | 지도의 붉은 지점이 파동처럼 퍼지고, 누르면 나라별 카드가 나타남 |

## GitHub Pages로 퍼블리싱하기

1. GitHub에서 새 저장소(repository)를 만든다.
2. 이 폴더 안의 파일을 **그대로** 업로드한다. 저장소 첫 화면에 `index.html`이 보여야 한다.
3. 저장소의 **Settings → Pages**로 들어가 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있다.

## 사용 서체

- 제목: 감탄로드 감탄체 (강원특별자치도, 무료 서체). 제목 글자만 남긴 경량 웹폰트.
- 본문: Noto Sans KR (Google Fonts)
